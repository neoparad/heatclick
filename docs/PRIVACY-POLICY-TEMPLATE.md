# クライアント向けプライバシーポリシー記載テンプレート

UGOKI MAPを導入するクライアントのプライバシーポリシーに追記してもらう文面のサンプル。
サイトの業種・対象地域に応じてカスタマイズすること。

---

## パターン1: 基本（行動分析のみ）

会員情報との紐付けを行わない場合。

```
【アクセス解析ツールの利用について】

当サイトでは、サービスの改善およびユーザー体験の向上を目的として、
アクセス解析ツール「UGOKI MAP」（提供元：Link TH Co., Ltd.）を利用しています。

UGOKI MAPは、以下の情報を自動的に取得します。
- ページの閲覧履歴、クリック・スクロール等の操作情報
- ご利用のブラウザ・デバイスの種類、画面サイズ
- 流入元のURL、検索キーワード（広告経由の場合）
- サイト内でのフォームの操作状況（入力内容自体は取得しません）

これらの情報は、個人を特定できない形で収集・分析されます。
データはLink TH Co., Ltd.が管理するサーバー（EU圏内）に保存されます。

トラッキングを無効にしたい場合は、ブラウザのローカルストレージに
「clickinsight_optout」を「true」に設定することで停止できます。
```

## パターン2: 会員情報との紐付けあり

ログインユーザーの行動データを会員情報と紐付けて分析する場合。

```
【アクセス解析ツールの利用および会員データとの連携について】

当サイトでは、サービスの改善およびユーザー体験の向上を目的として、
アクセス解析ツール「UGOKI MAP」（提供元：Link TH Co., Ltd.）を利用しています。

■ 取得する情報
UGOKI MAPは、以下の情報を自動的に取得します。
- ページの閲覧履歴、クリック・スクロール等の操作情報
- ご利用のブラウザ・デバイスの種類、画面サイズ
- 流入元のURL、検索キーワード（広告経由の場合）
- サイト内でのフォームの操作状況（入力内容自体は取得しません）
- 画像・動画コンテンツの閲覧状況
- セッション録画（画面操作の再現データ。入力フィールドの内容は自動的にマスクされます）

■ 会員情報との紐付け
ログイン済みのお客様については、上記の行動データを会員IDと紐付けて分析する場合があります。
これにより、お客様のご利用状況をより正確に把握し、サービスの改善に活用いたします。
なお、行動データと紐付けるのは会員IDのみであり、氏名・メールアドレス等の個人情報は
解析ツールのサーバーには送信されません。

■ データの利用目的
- サイトの利用状況の分析およびサービス改善
- コンテンツの最適化および表示改善
- お客様のご利用体験の向上

■ データの管理
行動データはLink TH Co., Ltd.が管理するサーバーに保存されます。
当社はLink TH Co., Ltd.との間でデータ処理に関する契約を締結し、
適切な管理体制のもとでデータを取り扱います。

■ オプトアウト
トラッキングを無効にしたい場合は、以下のいずれかの方法で停止できます。
- ブラウザのローカルストレージに「clickinsight_optout」を「true」に設定する
- 当サイトの設定画面からトラッキングを無効化する（対応している場合）
```

## パターン3: セッション録画を含む場合の追記

パターン1またはパターン2に追加。

```
■ セッション録画について
当サイトでは、ユーザー体験の改善を目的として、サイト上での操作を再現する
「セッション録画」機能を利用する場合があります。

録画データには以下のプライバシー保護措置が適用されます。
- フォームに入力されたテキスト（氏名、メールアドレス、パスワード等）は
  自動的にマスク処理され、記録されません
- 特定のページや要素を録画対象から除外することが可能です
- 録画データは個人を特定する目的では使用しません

録画を希望されない場合は、上記のオプトアウト方法でトラッキング自体を
無効化することで、録画も停止されます。
```
